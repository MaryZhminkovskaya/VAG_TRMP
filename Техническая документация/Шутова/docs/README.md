# Добро пожаловать в Виртуальную Арт-Галерею

Добро пожаловать в документацию по приложению **"Виртуальная Арт-Галерея"** — вашему цифровому пространству для искусства.

**Основные возможности приложения:**

1.  Просмотр коллекции картин в высоком качестве.
2.  Легкая загрузка и публикация собственных работ.
3.  Организация картин в персональные альбомы-выставки.
4.  Знакомство с картинами художников разных эпох с помощью удобного поиска
5.  Надёжная защита от нежелательного контента и строгая модерация
6.  Простой и понятный пользовательский интерфейс
